# AetherType 🌌✨

> **AetherType** is an interactive, browser-based kinetic typography and particle-physics simulation engine built entirely with vanilla web technologies. Part of the **Surman Code Hub** open-source initiative.

![AetherType Preview](https://github.com/SurmanCodeHub/AetherType/raw/main/preview.png)

## 🌐 Live Demo
Experience it live in your browser: [https://surmancodehub.github.io/AetherType/](https://surmancodehub.github.io/AetherType/)

---

## 🚀 Features
* **Kinetic Text Physics:** Real-time particle generation that transforms custom input text into interactive particle structures.
* **Mouse Interaction:** Dynamic force fields that allow users to scatter and interact with text pixels using mouse movement.
* **Zero Frameworks:** High-performance rendering powered purely by HTML5 Canvas and ES6+ JavaScript.
* **Responsive Design:** Automatically adapts to any viewport size or screen resolution.

---

## 🛠️ Tech Stack
* **HTML5 Canvas** (Graphics Rendering & Pixel Manipulation)
* **Vanilla JavaScript (ES6+)** (Physics Engine & Event Handling)
* **CSS3** (Modern UI & Glassmorphism Styling)
